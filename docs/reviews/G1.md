## Tái hiện lỗi trên phiên bản trước

Chạy từ root. Fixture là dữ liệu giả lập.

```powershell
@'
import json
from fastapi.testclient import TestClient
from apps.api.main import app

with TestClient(app) as client:
    requests = [
        ("/api/analyze", {"text": "Patient QA Fixture.", "language": "en", "mode": "rules"}),
        ("/api/redact", {"text": "QA fixture.", "entities": []}),
    ]
    for path, payload in requests:
        for encoding in ("utf-8", "utf-16-le", "utf-16", "utf-32"):
            response = client.post(
                path,
                content=json.dumps(payload).encode(encoding),
                headers={"Content-Type": "application/json"},
            )
            print(path, encoding, response.status_code, response.json().get("error"))
'@ | uv run --locked python -
```

Quan sát `200 None` cho tám request trên `c47a597`. Với bản sửa `30c7440`, cùng phép kiểm trả 200 cho hai request UTF-8 và 422 cho sáu request UTF-16/UTF-32.
